# v3.29 界面与登录恢复验收

日期：2026-10-23。共享 Web 前端更新为 3.29，桌面壳版本仍为 0.6.2。用户确认采用石墨灰与暖白，蓝色用于重点操作；按钮需要实体厚度，AI 对话接近 Codex 的简洁层级。

## 变更

- 修复启动时重复打开授权网页：调试服务重放旧授权事件，旧前端会把陌生请求 ID 当成当前登录并打开 URL。现在只有已登记的登录请求才会处理，且只有当前页面主动发起的登录可以自动打开浏览器。恢复账户、刷新与重启保留登录、模型和历史。
- 控制台增加独立的实体按钮样式层：标准控件使用高光、柔和阴影、下缘与 1px 按压反馈；急停保留独立危险按钮反馈。内容面层保持平整，深浅主题共用语义令牌，六套配色仍可选择。
- 阶段名称与时间逐行对齐；事件详情可展开，完整数值可以换行。移除重复曲线名称和读数说明。图表事件按钮根据内容撑开，按实际容器空间适配缩放。
- 对话只保留历史、新对话、更多和关闭四个头部入口。模型与账户选择放在输入区；附件保留一个入口；放大、账户设置、重命名与删除收在对话选项中。消息操作改为带明确名称的图标。
- AI 入口移至顶部栏，输入区采用单一内凹容器。宽屏保留侧栏和放大视图，窄屏占用工作区，短横屏分开阅读与输入；急停位于独立底栏。
