日期：2026-10-27。用户确认使用 USB-RS485 直接接电脑，同时保留迁移至树莓派；硬件沿用 TC4S、9600、8N1、站号 1。

## 交付行为

- 主页操作台顶部仅 CC、FC、SC、End；取消一爆结束／二爆结束操作和大号“下一事件”按钮。原生文件及历史数据仍保持兼容。
- 启动默认真实设备。Windows 内置 Python 控制服务由 Rust 管理，绑定随机本机端口。源码调试入口也默认使用实际 Python 控制器。
- 设置显示真实串口列表、波特率、站号和状态。合法 PV/SV 响应后才就绪；没有遥测时显示 `--`，不能开始烘焙。启动／重连不会写 SV 或自动开始。
- 模拟器必须在设置中选择并连接。真实／模拟曲线及记录隔离，控制服务重启后恢复真实模式。串口参数保留；刷新串口不覆盖未保存的参数。
- 有未处理本锅时禁止切换设备／模式，所属本机控制进程拒绝退出。未授权来源的浏览器写操作和 WebSocket 被拒绝，所属进程令牌保护关闭接口。
- 服务地址切换后 AI 仍使用本机配置；已有账户、模型与历史保留。旧对话仍须通过历史列表明确打开。
- 树莓派部署包仅监听本机；电脑通过既有 SSH 登录建立端口隧道。安装脚本安装依赖、保留配置并添加启动入口，不执行烘焙。
