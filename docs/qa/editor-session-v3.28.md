## 修复结果

- 顶部信息栏使用内容自适应高度，44px 输入控件不再被画布覆盖。移除重复图例，节点和 RoR 列表随侧栏统一滚动；手机页面使用文档滚动，长内容完整可达。
- AI 对话入口放入编辑器工具栏。宽屏停靠为画布留出空间；放大视图取消主控制台的左侧导航留白。窄屏与放大视图禁用背景编辑，关闭后恢复入口焦点。
- 桌面启动器直接调用 Tauri CLI API，避免把 `ai-node-x86_64-pc-windows-msvc.exe` 错识别为子命令。资源准备直接使用同一 Node；CMD 保留真实失败退出码，并检查开发依赖与 Rust。CMD 先启动或复用固定本机调试服务，供网页和桌面共用。
- 网页与调试桌面使用同一本机加密账户空间。正式客户端继续使用自己的持久化本机空间。恢复账户、模型与会话时不启动交互式授权；正常令牌轮换加密落盘。临时网络故障保留授权，只有明确授权拒绝才要求登录。用户主动退出的账户保持退出。
